# Alice — WordPress Fashion Theme

Alice is a lifestyle-editorial WordPress Block Theme for fashion stores. It provides presentation for WordPress and WooCommerce's native content and store functionality. WooCommerce is needed for ecommerce features; without it, general WordPress pages remain usable.

The theme uses native blocks, templates, template parts, patterns, `theme.json`, and CSS. It does not add custom blocks, business logic, or external-service integrations.

See [the project overview](docs/00.project-overview.md) for scope and design decisions, and [AGENTS.md](AGENTS.md) for implementation guidance.
