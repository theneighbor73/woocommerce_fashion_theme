# Alice SVG Icon Set

16 minimalist outline icons, each supplied in two color variants (32 SVG files total).

## Folders
- `light/`: stroke `#222222` for light surfaces.
- `dark/`: stroke `#F9F8F6` for dark / inverse surfaces.

## Usage
All SVGs use a `24 × 24` viewBox, transparent background, no embedded raster assets,
and editable stroke paths. The stroke width is `1.65` with rounded caps and joins.

Example:
```html
<img src="/icons/light/shopping-cart.svg" width="24" height="24" alt="">
```

For inline SVG, paste the file contents into your template. You can also change the
`stroke` value to `currentColor` if you prefer CSS-driven coloring.
