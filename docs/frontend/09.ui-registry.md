# UI Registry

Record approved UI specifications here before implementation. Keep entries concise and link to a more detailed specification only when one is needed.

Each entry should include:

- Name and status (`IN_PROGRESS` or `IMPLEMENTED`).
- Visual structure and content/data shown.
- Merchant-editable areas and locking behavior.
- Native WordPress/WooCommerce behavior and visual interaction states.
- Responsive and accessibility requirements.

Do not specify custom business behavior here. Requirements outside the approved theme boundary must be escalated and decided before implementation.
