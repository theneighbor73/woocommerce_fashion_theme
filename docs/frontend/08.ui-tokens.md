# UI Tokens

This file records approved design tokens. The six palette values are approved and mapped to semantic tokens below. Typography, spacing, layout, border, and motion tokens remain undecided; do not treat earlier sample values or generic WordPress presets as project decisions. Add those tokens after the design choices are approved.

## Color tokens

| Token | Value | Role |
|---|---|---|
| `--color-bg-page` | `#F9F8F6` | Page canvas and subtle backgrounds |
| `--color-bg-inverse` | `#111111` | Header, footer, and dark surfaces |
| `--color-text-heading` | `#111111` | High-contrast headings and key text |
| `--color-action-primary` | `#111111` | Primary buttons and key actions |
| `--color-text-primary` | `#222222` | Body text and supporting headings |
| `--color-accent-primary` | `#C5A059` | Sale badges, selected states, and promotional emphasis |
| `--color-border-subtle` | `#E5E5E5` | Dividers, boundaries, and form borders |
| `--color-status-error` | `#C62828` | Validation errors and critical notices |
| `--color-text-inverse` | `#F9F8F6` | Text on dark surfaces |
| `--color-focus-ring` | `var(--color-action-primary)` | Keyboard focus indicator |

These semantic names may map to WordPress `theme.json` presets when those presets are implemented. Keep the six palette values unchanged unless the project owner approves a change. Update this table when approved token definitions change.
