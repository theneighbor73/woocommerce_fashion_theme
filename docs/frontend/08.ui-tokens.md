# UI Tokens

This file records approved design tokens. The six foundational palette values are extended with distinct muted-text, subtle-accent-surface, and success-feedback colors. Typography assets must be free/open licensed, bundled locally, and have source and license records before shipping.

## Color tokens

| Token | Value | Role |
|---|---|---|
| `--color-bg-page` | `#F9F8F6` | Page canvas and subtle backgrounds |
| `--color-bg-inverse` | `#111111` | Header, footer, and dark surfaces |
| `--color-text-heading` | `#111111` | High-contrast headings and key text |
| `--color-action-primary` | `#111111` | Primary buttons and key actions |
| `--color-text-primary` | `#222222` | Body text and supporting headings |
| `--color-accent-primary` | `#C5A059` | Sale badges, selected states, and promotional emphasis |
| `--color-border-subtle` | `#E5E5E5` | Dividers, boundaries, and form borders |
| `--color-status-error` | `#C62828` | Validation errors and critical notices |
| `--color-text-inverse` | `#F9F8F6` | Text on dark surfaces |
| `--color-text-muted` | `#666666` | Secondary text and metadata; 5.41:1 contrast against Canvas |
| `--color-accent-subtle` | `#F2E8D4` | Warm, subtle accent surface; not for text or essential boundaries |
| `--color-status-success` | `#2F6B45` | Success text and icon on light surfaces; pair with a clear label, not color alone |
| `--color-focus-ring` | `#111111` | Keyboard focus indicator |

The semantic extensions are available as WordPress color presets and CSS tokens; current component CSS does not yet consume them. Success text has 5.98:1 contrast against Canvas. The brand accent `#C5A059` has 2.32:1 contrast against Canvas, so reserve it there for decorative emphasis; it has 7.69:1 contrast against the dark primary surface. Check contrast and focus visibility on each actual surface against the WCAG 2.2 AA target.

## Typography

Use the locally bundled variable font files listed below. Both include SIL Open Font License 1.1 files in their folders; keep those license files with the font assets. Use the variable files rather than the duplicate static font sets unless compatibility review identifies a need for static files.

| Token | Value / fallback | Use |
|---|---|---|
| `--font-serif` | `"Cormorant Garamond", Georgia, serif` | Editorial display headings and pull quotes; `assets/fonts/Cormorant_Garamond/CormorantGaramond-VariableFont_wght.ttf` |
| `--font-sans` | `"Plus Jakarta Sans", -apple-system, BlinkMacSystemFont, sans-serif` | Body, product, navigation, and controls; `assets/fonts/Plus_Jakarta_Sans/PlusJakartaSans-VariableFont_wght.ttf` |

Font sources: [Cormorant](https://github.com/CatharsisFonts/Cormorant) and [Plus Jakarta Sans](https://github.com/tokotype/PlusJakartaSans). The downloaded files include their OFL license texts and README files.

## Spacing and layout

| Token | Value |
|---|---|
| `--space-xs` / `--space-sm` / `--space-md` | `0.5rem` / `1rem` / `1.5rem` |
| `--space-lg` | `clamp(2rem, 4vw, 3rem)` |
| `--space-xl` | `clamp(3.5rem, 6vw, 5rem)` |
| `--space-2xl` | `clamp(5rem, 9vw, 8rem)` |
| `--layout-content-max` | `47.5rem` |
| `--layout-wide-max` | `85rem` |
| `--layout-gutter` | `var(--space-md)`, scaling to `var(--space-lg)` on desktop |
| `--product-aspect-ratio` | `3 / 4` |

Reference breakpoints: mobile `< 37.5rem`, tablet `37.5rem–63.9375rem`, desktop `64rem–84.9375rem`, and wide `≥ 85rem`. Product grids use 2, 3, and 4 columns on mobile, tablet, and desktop respectively. Curated editorial collections may use 3 columns on desktop.

## Controls, borders, elevation, and motion

| Token | Value |
|---|---|
| `--control-height-base` / `--control-height-sm` | `3rem` / `2.375rem` |
| `--button-padding-x` / `--input-padding-x` | `1.75rem` / `1rem` |
| `--radius-none` / `--radius-sm` / `--radius-full` | `0` / `2px` / `9999px` |
| `--border-width-thin` / `--border-width-thick` | `1px` / `2px` |
| `--shadow-none` | `none` |
| `--shadow-overlay` | `0 12px 32px rgb(17 17 17 / 0.08)` |
| `--z-base` / `--z-sticky` / `--z-dropdown` / `--z-modal` | `1` / `100` / `200` / `400` |
| `--ease-editorial` | `cubic-bezier(0.22, 1, 0.36, 1)` |
| `--duration-fast` / `--duration-base` / `--duration-media` | `200ms` / `350ms` / `600ms` |

Use square corners by default. Reserve the full radius for small swatches and count badges. Use overlay shadow only for floating layers. Respect reduced-motion preferences.
