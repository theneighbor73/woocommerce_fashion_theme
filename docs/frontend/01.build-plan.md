# Build Plan

Build the theme in small, reviewable parts. Use native WordPress/WooCommerce behavior from the start; refine its presentation without postponing or recreating its functionality.

Before implementing each UI element, record its approved specification in the UI registry.

## Phase 1 — Theme foundation

- Initialize the Alice block theme and activate it in the local WordPress environment.
- Approve the remaining global design tokens (typography, spacing, widths, breakpoints, grid, controls, and motion), then establish them in `theme.json` and CSS before building templates or template parts.
- Build the fixed-composition header (logo left, navigation right) and footer from native blocks/template parts.
- Keep merchant-editable logo, navigation content, text, and media available through native tools.

## Phase 2 — Core shopping experience

- Implement the prebuilt native-block homepage with editorial content and a WooCommerce product collection; do not seed database content on activation.
- Integrate native WooCommerce catalog, product, account, and search presentation.
- Style both WooCommerce block-based and classic shortcode-backed Cart and Checkout pages while preserving native behavior.
- Refine responsive and accessible states without replacing native behavior.

## Phase 3 — Editorial and secondary pages

- Implement blog, editorial, standard content, archive, and 404 templates per the sitemap.

## Phase 4 — Review and refinement

- Refine design consistency, responsiveness, and native editor behavior.
- Escalate any requirement that needs custom functionality or an external service before proceeding.
