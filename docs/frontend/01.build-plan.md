# Build Plan

Build the theme in small, reviewable parts. Use native WordPress/WooCommerce behavior from the start; refine its presentation without postponing or recreating its functionality.

## Phase 1 — Theme foundation

- Initialize the Alice block theme and activate it in the local WordPress environment.
- Establish `theme.json`, base styles, and the approved palette tokens.
- Build the fixed-composition header and footer from native blocks/template parts.
- Keep merchant-editable logo, navigation content, text, and media available through native tools.

## Phase 2 — Storefront templates

- Implement homepage, page, post, archive, search, and 404 presentation per the sitemap.
- Integrate native WooCommerce templates/blocks for product catalogs, product details, cart, checkout, and account pages.
- Refine responsive and accessible states without replacing native behavior.

## Phase 3 — Review and refinement

- Record each UI element in the UI registry before implementation.
- Refine design consistency, responsiveness, and native editor behavior.
- Escalate any requirement that needs custom functionality or an external service before proceeding.
