# Custom Block Consideration List

This is a decision backlog, not authorization to build custom blocks or install plugins. Add an item only after the project owner directs that it be recorded.

When a requirement cannot be met with native WordPress/WooCommerce features and permitted visual enhancements, stop and present:

1. The requirement and why native options fall short.
2. A native fallback and its trade-offs.
3. An existing-plugin option, if one is suitable.

The project owner decides whether to use a fallback, defer the requirement, or record it here for future review. Do not scaffold or implement a custom block from this list.
