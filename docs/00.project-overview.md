# Project Overview

## Purpose

Alice is a reusable WordPress Block Theme for fashion stores using WooCommerce. It gives merchants a coherent storefront presentation while WordPress and WooCommerce provide the store's content and commerce capabilities. [Technical Constraints](constraints/05.technical-constraints.md) define the implementation boundary for that product decision.

## Product scope

The theme presents content and native WordPress/WooCommerce functionality. It does not own merchant business behavior or business data. Custom commerce features, external-service features, and custom blocks are outside the approved product scope. If a requirement needs one of these, use the decision process in the [Custom Block Consideration List](consideration-list.md) before proceeding.

## Default activation experience

The theme provides a prebuilt `front-page.html` composition using native blocks, including editorial content and a WooCommerce product collection. Activation does not create or seed WordPress pages, products, or other database content. Merchants can edit intended text and media through native editor tools. The product collection uses the store's existing catalog and should remain presentable when that catalog is empty.

During theme development, clearly replaceable sample copy may be used in templates, including taglines, addresses, and contact details. Use unmistakable placeholders such as `Example Street` and `example.com`; do not present invented business information as verified merchant facts. Keep the copy editable through native WordPress blocks.

## Visual direction

The shared visual direction is minimalist, contemporary fashion with a lifestyle-editorial feel. See [Design Foundations](frontend/design-system-reference.html) for visual principles and [UI Tokens](frontend/08.ui-tokens.md) for approved color roles, values, and other design tokens.

## Theme identity

Theme name: **Alice**. Theme slug: **`alice-theme`**. Use the slug for WordPress handles and text domain; use a valid underscore form such as `alice_theme_` for PHP identifiers. The repository is the source of truth for theme structure.
